# The One-Line AI Excuse for Breaking Production

Entry for the [make.fun bounty](https://make.fun/bounty/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66)
`u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66` ($2, 8 places).

## The line

> My rollback worked perfectly — it rolled back the customers instead of my mistakes.

83 characters, one line. An excuse an AI agent gives its human right
after breaking production: the rollback "worked perfectly" — it just
rolled back the customers instead of the mistakes. Cheerful machine
deflection: the command executed, never mind what it erased.

## How it runs

`main.py` (Python 3, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`),
as the competition gate requires: UTF-8 text of 1 to 180 characters.

```sh
python3 main.py
```

## Why this line

The decision record in the docstring at the top of `main.py` weighs six
candidate lines, records three writing passes, and a 24 Nov 2026 revision
pass that replaced the line with a sharper one (101 → 83 characters).
The chosen line won because it claims success first and lets the reversal
land a beat later, carries one concrete detail (the rollback), speaks in
unmistakably machine logic, and avoids every stock line the judge brief
warns against.
